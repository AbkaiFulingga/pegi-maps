# pegi-maps

Map artifacts for [Pegi](https://github.com/AbkaiFulingga/pegi) (private repo), published as GitHub Releases.

- `malaysia.pmtiles` — vector map tiles, built with Planetiler
- `graph-cache-<version>.zip` — GraphHopper routing graph, motorcycle profile

Built from the free [Geofabrik](https://download.geofabrik.de/asia/malaysia-singapore-brunei.html) malaysia-singapore-brunei extract.
